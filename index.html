        Client-Side Security Model
      

      
    


    

      

        Zero-Proxy Direct Calls: All HTTP fetch requests are dispatched straight from your browser engine to https://api.groq.com/openai/v1/*. No telemetry, logs, or intermediate servers ever see your requests or keys.
      

      

        Session Scope: When remembering keys is enabled, data is stored in the browser's sessionStorage. Closing the tab purges the key permanently.
      

      

        Advisory: Browser-side memory is readable by browser extensions and developer tools. Do not use unrestricted production master keys on public or shared computers.
